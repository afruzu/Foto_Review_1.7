Il file complementare "crea_calderone.ps1" presente in questo repository contiene uno script in PowerShell che provvede a "trasportare" tutti i files contenuti nelle sottocartelle della cartella radice in quest'ultima, svuotando completamente le sottocartelle stesse. 
Questa operazione si rende necessaria in via preliminare se si vuole sottoporre a classificazione ed esame immagini che abbiano già una precedente strutturazione in sottocartelle, visto che il programma Foto_Review non prevede la scansione ricorsiva all'interno della cartella radice ed elabora esclusivamente le immagini presenti nel primo livello di quest'ultima.
Copiare lo script nella cartella radice da elaborare e lanciarlo da terminale con PowerShell.
